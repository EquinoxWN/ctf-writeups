# Quality check against the 10 rules (2026-11-01)

Run on 2026-11-09 on Windows 11 (Intel Core i7-13700H) with Python 3.14.5 in the repo's `.venv`.
The checks were applied while M1 was built. Mutations were applied one at a time by a script
that replaced one exact string, ran `pytest -q -x`, and restored the original bytes in a
`finally` block right after each run.

| # | Rule | Status | Evidence |
|---|---|---|---|
| 1 | Assume every call can fail | pass | No network calls. File reads catch `OSError` and report it as a problem with the path; decoding is strict UTF-8; TOML errors become problems with a line. The padding-oracle attack raises when no byte value works, and every solver raises when it finds no flag. No `except` swallows an error (`sqlite3.Error` in the vulnerable login is turned into the "database error" page the challenge needs). |
| 2 | Writes safe to retry | pass | `INDEX.md` is written to a temp file in the same directory, fsynced and renamed with `os.replace`; a failed rename removes the temp and keeps the old file (tested). `ctfw new` opens with mode `x`, so it never overwrites. Running `ctfw index` twice gives the same bytes. |
| 3 | No race conditions | N/A | Single-threaded CLI; the only shared file is written by atomic rename. |
| 4 | Don't trust the clock | pass | `solved` is compared with today's date in UTC (`datetime.now(UTC)`), and the date is injected in tests. Solve durations use `time.monotonic`. |
| 5 | Read before changing | pass | No environment variables are read. Every link in the README and docs exists (`audit_repo.py`). |
| 6 | Never break compatibility | N/A | First release; the front matter keys and section names are documented in the README and ADR 0002. |
| 7 | One source of truth | pass | Techniques live only in `techniques.toml`; the index is generated from it and checked in CI; flags live only in the practice modules and write-ups hold their sha256. Python >=3.11 in `pyproject.toml`, 3.12 in CI. |
| 8 | Small changes, no secrets, validate input | pass | Every flag, key and password is marked `EXAMPLE-NOT-A-SECRET` and a test enforces it for flags and scans for key and token patterns. Input bounds: write-ups 256 KiB, vocabulary 64 KiB, PNG chunk count 1,024, decompressed text 64 KiB, chunk lengths checked against the file, CRCs verified; symbolic links refused; slugs restricted to `[a-z0-9-]`. |
| 9 | Tests that can actually fail | fixed | Every rule has a test that breaks it. 9 of 10 mutants were killed at first; the survivor showed the false-positive test never triggered a false positive, and the fixed test kills it. |
| 10 | Re-verify | pass | Results below. |

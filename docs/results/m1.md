## Analyze and Improve

- The first run of `ctfw check` failed all four write-ups: they were dated 2026-11-09 in local
  time (UTC+7) while the UTC date was 2026-11-08. The rule compares with the UTC date on purpose
  (so CI and laptops agree); the write-ups were re-dated.
- The first test run failed nine tests on Windows: files written with CRLF left a bare `\r` at the
  end of the TOML block. The parser now reads CRLF as LF, and a test covers it.
- Mutation testing found one weak test: the padding-oracle false-positive case never triggered,
  because the attack forges from a zero block and the test used a plaintext that only causes a
  false positive with the real previous block. The test now chooses the plaintext byte from the
  IV so the false positive happens every time. See [docs/quality/2026-11-01.md](../quality/2026-11-01.md).
